Datenschutz

Diese Website ist eine statische Website. Sie verwendet keine Cookies, kein Tracking und keine Analyse-Werkzeuge.

Damit der Kalender sich merkt, welche Türchen schon geöffnet wurden und ob der Schnee an oder aus ist, speichert er das im Browser (Local Storage). Diese Angaben bleiben auf dem Gerät und werden nicht übertragen.

Die Website wird über GitHub Pages (GitHub, Inc.) bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse, siehe die Datenschutzerklärung von GitHub. Alle Bilder und Inhalte werden von dieser Website selbst ausgeliefert.

Bildnachweise

Alle Bilder stammen von Wikimedia Commons und stehen unter freien Lizenzen. Urheber und Lizenz stehen unter jedem Bild und auf der Seite „Bildnachweise“ des jeweiligen Kalenders.
